# Bulldog Fantasy Draft Analysis

A personal, non-commercial fantasy football draft analysis tool built for use with my own Yahoo Fantasy Football league.

## Purpose

This application uses read-only data from the Yahoo Fantasy Sports API to assist with fantasy football draft preparation and live draft analysis.

The application is designed for a single user and a single Yahoo Fantasy Football league.

## Data Used

The application may retrieve:

- League settings and scoring configuration
- Teams and rosters
- Player information
- Draft results
- Available player information

This information is used to evaluate player value based on the league's custom scoring system, monitor roster construction, and provide draft recommendations.

## Access

This is a personal project and is not offered commercially or made available as a public fantasy football service.

The application requires read-only access to Yahoo Fantasy Sports data.

It does not make automated draft selections, roster transactions, trades, waiver claims, or other changes to Yahoo Fantasy teams.

## Security

OAuth credentials, access tokens, refresh tokens, and other private authentication information are not stored in this public repository.
